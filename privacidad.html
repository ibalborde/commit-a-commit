Política de privacidad

Commit a Commit uploader · Última actualización: 22 de noviembre de 2026

Commit a Commit uploader (“la herramienta”) es un script privado que usa únicamente el dueño del canal de YouTube Commit a Commit para subir sus propios videos. Esta política explica qué datos usa y cómo.

Servicios de YouTube y Google

La herramienta usa los Servicios de la API de YouTube. Al usarla, aceptás las Condiciones del servicio de YouTube. Los datos se tratan además según la Política de privacidad de Google.

Qué datos usa

  • Token de autorización OAuth que Google entrega cuando el dueño del canal da permiso. Se usa para llamar a la YouTube Data API en su nombre.
  • Datos del propio canal: nombre, ID del canal y listas de reproducción, solo para confirmar el canal de destino.
  • Contenido que se sube: videos, miniaturas, subtítulos, títulos, descripciones y etiquetas creados por el dueño del canal.

La herramienta no accede a datos de otros usuarios, suscriptores, comentarios, estadísticas ni a ningún otro dato de la cuenta de Google.

Dónde se guardan

El token y los IDs de los videos subidos se guardan solo en la computadora del dueño del canal, en archivos locales con acceso restringido. No hay servidores, bases de datos ni servicios de terceros. La herramienta no usa cookies, analítica ni publicidad.

Con quién se comparten

Con nadie. Los datos solo viajan entre la computadora del dueño del canal y Google/YouTube a través de la API oficial. No se venden, no se ceden y no se transfieren a terceros.

Cómo revocar el acceso y borrar los datos

El acceso se puede revocar en cualquier momento desde la página de permisos de la cuenta de Google. Para borrar los datos guardados, alcanza con eliminar el archivo del token en la computadora donde corre la herramienta. Los IDs de los videos subidos se guardan solo para poner el link de cada video en las descripciones del propio canal; se pueden borrar en cualquier momento.

Cambios y contacto

Si esta política cambia, se actualiza esta página y la fecha de arriba. Consultas: commitacommit.dev@gmail.com.

Privacy Policy

Commit a Commit uploader · Last updated: November 22, 2026

Commit a Commit uploader (“the tool”) is a private script used only by the owner of the YouTube channel Commit a Commit to upload their own videos. This policy explains what data it uses and how.

YouTube and Google services

The tool uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Data is also handled under the Google Privacy Policy.

What data it uses

  • OAuth authorization token issued by Google when the channel owner grants permission. It is used to call the YouTube Data API on their behalf.
  • The channel's own data: name, channel ID and playlists, only to confirm the destination channel.
  • Uploaded content: videos, thumbnails, captions, titles, descriptions and tags created by the channel owner.

The tool does not access data about other users, subscribers, comments, analytics, or any other Google account data.

Where it is stored

The token and the IDs of uploaded videos are stored only on the channel owner's computer, in local files with restricted access. There are no servers, databases or third-party services. The tool uses no cookies, analytics or advertising.

Who it is shared with

No one. Data only travels between the channel owner's computer and Google/YouTube through the official API. It is not sold, disclosed or transferred to third parties.

Revoking access and deleting data

Access can be revoked at any time from the Google account permissions page. To delete stored data, delete the token file on the computer where the tool runs. The IDs of uploaded videos are kept only to link each video in the channel's own descriptions; they can be deleted at any time.

Changes and contact

If this policy changes, this page and the date above are updated. Questions: commitacommit.dev@gmail.com.
